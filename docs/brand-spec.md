# BlockFace 品牌与界面规范

> 依据：用户选定的方向 **A · blockgrid**（`design-demos/A-blockgrid.html`）。
> 本文件是实现的唯一视觉依据：`src/styles/tokens.css` 必须与本文件的令牌表逐条对应。

## 1. 品牌定位

| 项 | 内容 |
| --- | --- |
| 名称 | BlockFace |
| 一句话 | 给图片贴 MC 头像 |
| 中文副题 | 头图合成器 |
| 许可 | Apache License 2.0 |
| 作者 | Dainsleif |
| 语气 | 工位工具、干练、方块感；不自称"AI"，不卖萌，不用感叹号 |
| 与 Minecraft 的关系 | 兼容其皮肤贴图格式的**独立第三方工具**；不使用任何 Minecraft 商标、logo 或官方字体 |

## 2. 设计原则（方向 A 的方法论）

1. **控件即积木**。界面上没有装饰性图形，所有视觉元素都是"可被理解的方块"：面板身份是 4px 色条，开关是方块滑子，滑杆手柄是 14px 方块，选中标记是 3px 外描边。
2. **8px 是唯一网格**。间距、控件高度、图标尺寸全部落在 8 的倍数或半数（4/8/12/16/20/24/32/40）。
3. **全平涂硬边**。没有渐变、没有阴影堆叠、没有圆角（唯一例外见 §7）。层级只能靠三样东西表达：1px 墨线描边、色条、底色深浅。
4. **像素内容优先**。皮肤是像素画，所以渲染一律最近邻（`image-rendering: pixelated`、`imageSmoothingEnabled = false`），界面也必须是硬边，避免"软壳包硬芯"。
5. **状态必须可读**。任何联网、耗时、失败状态都要有文字，不靠颜色单独承载语义。

## 3. 颜色令牌

```
--ink        #14110F   墨（正文/描边/选中底）      对比度 16.5:1 on --paper
--ink2       #5F584E   次墨（说明文字）            对比度 6.1:1 on --paper / 7.0:1 on --white
--line       #CFC8BA   浅描边（卡片/分隔）
--paper      #F2EFE6   纸（页面底）
--rail       #F7F5EF   栏底（左右侧栏）
--white      #FFFFFF   白（卡片/输入框/顶栏底）
--grass      #4E9A3D   草绿  — 内容与资产
--gold       #E0A526   金    — 联网与数值
--cyan       #3FA9AF   青    — 本地文件与开关
--red        #C8402F   红石  — 直改与破坏性操作（**仅限图形，禁止作文字色**）
--red-ink    #9E2E1E   深红  — 需要红色文字时使用，6.4:1 on --paper
--stage      #232019   画布底
--stage-line rgba(242,239,230,.075)  画布 8px 网格
--stage-major rgba(242,239,230,.16)  画布 40px 粗网格
```

**色条的语义映射（固定，不得随手换）**

| 颜色 | 承担 |
| --- | --- |
| 草绿 | 皮肤资产：内置皮肤、已载入皮肤、图层列表 |
| 金 | 联网与数值：正版账号 ID、位置/大小/旋转/不透明度滑杆 |
| 青 | 本地与开关：上传皮肤、帽子层、水平翻转 |
| 红石 | 直改与破坏：皮肤 URL 加载、重置变换、复制/删除 |

**红色使用限制**：`--red` 在纸底上的对比度只有 4.3:1，**不得用于文字**。它只出现在画布手柄、色条、状态灯、图标描边这类图形上。需要红色文字时用 `--red-ink`（6.4:1）。

## 4. 字体阶梯

```
--sans  "Segoe UI", system-ui, -apple-system, "Microsoft YaHei", "PingFang SC", "Noto Sans SC", sans-serif
--mono  "Cascadia Mono", Consolas, "SFMono-Regular", Menlo, monospace
```

| 用途 | 字号 / 字重 | 字体 |
| --- | --- | --- |
| 品牌名 | 17px / 700 | mono |
| 区块标题 h3 | 13px / 700 | sans |
| 正文、按钮、输入 | 13–14px / 400–600 | sans |
| 数值、坐标、规格 | 12–13px / 700 | mono |
| 说明、标签、状态栏 | 12px / 400 | sans |

**硬下限**：正文 ≥14px（表意性长文本）、控件与标签 ≥12px。**不得出现小于 12px 的文字。**
**对比度**：文字 ≥4.5:1（大字号 3:1），图标与描边等非文本 ≥3:1。改完界面跑一次
`node tools/cdp.mjs --url http://localhost:5178/ --pre-file tools/probe-contrast-pre.js --expr-file tools/probe-contrast.js --json`，
它会把每段文字的前景与逐层合成出来的背景一起算，比肉眼可靠。

## 6. 组件语法

- **按钮** `.bf-btn`：白底 + 1px 墨边；主行动 `.bf-btn--go` 草绿底 + 右上切角（`clip-path: polygon(0 0, calc(100% - 11px) 0, 100% 11px, 100% 100%, 0 100%)`）；次要 `.bf-btn--quiet` 用 `--line` 描边；图标按钮 34×34。
- **色条区块** `.bf-sblk`：左侧 4px 色条 + 标题行（h3 + 右侧 12px 说明）。整页所有分区都用它。
- **卡片** `.bf-card`：白底 + `--line` 描边；选中态 = 墨色描边 + `outline:1px` 外扩 3px（双线框），并在左上角挂一个草绿切角旗标。
- **分段控件** `.bf-seg`：整体 1px 墨框，选中项墨底纸字。
- **开关** `.bf-tg`：40×20 轨道 + 16px 方块滑子，开启时轨道变草绿、滑子右移 20px；右侧永远带文字状态（"已开启/已关闭"）。
- **滑杆** `.bf-sl`：8px 轨道（内部叠 12px 刻度虚线）+ 青色填充 + 14px 方块手柄（内部 4px 纸色方孔）；上方左侧 12px 标签、右侧 mono 数值框。
- **图层行** `.bf-lay`：42px，左侧 4px 色条（选中转草绿），26px 缩略图框，mono 名称，右侧 mono 说明。
- **输入框** `.bf-inp`：32px 高，1px 墨边，13px mono；placeholder 回退 sans 12px 次墨。
- **状态芯片** `.bf-chip`：24px 高纸底墨字；画布底上的芯片用 `.bf-chip--dark`（透明底 + 纸色描边）。
- **拖放区** `.bf-drop`：虚线墨框 + 8px 方格底纹。

## 7. 图标与例外

- 图标**必须**是纯 CSS 方块拼装（`.bf-ic-*`），与文字同色（`currentColor`）。**禁止 emoji、禁止图标字体、禁止位图图标。**
- 全站唯一的圆角是**焦点环**：`:focus-visible` 用 2px 墨色 outline，这是无障碍要求，不视为风格破例。
- 全站唯一的斜切是导出按钮的切角。
- 唯一允许的投影是**浮层**（提示条、拖放遮罩），且只能是单层硬投影。

## 8. 画布与手柄

- 画布区底色 `--stage`，叠 8px/40px 双层网格。
- 画板（文档）本身：1px 墨线描边，无底色（有底图时是底图，无底图时是棋盘格）。
- 选中框 `.marquee`：1px 墨线 + 1px 纸色外描边（`outline-offset:1px`），保证在深色和浅色照片上都可见。
- 四个角手柄：11×11 红色方块 + 1px 墨边。
- 四条边手柄：18×6 / 6×18 红色条 + 1px 墨边。
- 旋转手柄：2px 红色竖杆（32px）+ 12×12 纸色方块旋钮（内含 3px 红石方孔）。

## 9. 无障碍

- 所有正文对比度 ≥4.5:1（实测：墨/纸 16.5:1，次墨/纸 6.1:1，深红/纸 6.4:1）。
- 图标按钮必须有 `title` 与 `aria-label`；开关用 `role="switch"` + `aria-checked`。
- 键盘：方向键微调选中头像（Shift 加速），`Delete` 删除，`Ctrl+Z` / `Ctrl+Shift+Z` 撤销重做。
- 状态不靠颜色单独表达：草绿旗标旁有"使用中"文字，开关旁有"已开启/已关闭"。
- 焦点可见：任何可聚焦元素在键盘操作下都有 2px 墨色焦点环。

## 10. 禁用清单

- ❌ Minecraft 官方 logo、商标、「我的世界」字样或官方字体
- ❌ emoji 作为图标
- ❌ 渐变、多层阴影、大圆角、玻璃拟态
- ❌ 小于 12px 的文字
- ❌ 用颜色单独承载语义
- ❌ lorem ipsum 或占位英文假文案
- ❌ 把用户图片上传到任何服务器（产品承诺"本地计算"）
