## 一、产品是什么

**BlockFace** 是一个**纯前端**（Vue 3 + Vite，无后端、无账号体系、图片不上传服务器）的浏览器图像工具：
用户上传一张图片作为底图，在上面叠加 **Minecraft 玩家头像**，拖动/缩放/旋转摆好位置，导出 PNG。
皮肤来源四条：内置 Steve/Alex、输入正版账号 ID 查询、上传皮肤 PNG、粘贴皮肤 URL。全部计算在本地浏览器完成。

## 二、受众与使用场景

- **主受众**：Minecraft Java 版玩家，16–28 岁。用途集中在：群聊表情与头像、服务器宣传图、玩家名录、皮肤作品展示图、视频/帖子封面。
- **技术水平**：会用电脑、会截图、会逛 MCBBS/贴吧，但**不是设计师**。对"图层""蒙版""混合模式"没有专业认知。
- **使用场景**：桌面浏览器（Chrome/Edge），视口 ≥1440×900，鼠标为主，单手操作。
- **核心体验目标**：**从打开到导出 ≤ 30 秒，全程不需要看说明书。** 用户的心智模型是"贴贴纸"，不是"做图像处理"。
- **失败的样子**：任何让人联想到 Photoshop 的复杂度——几十个面板、专业术语、模式弹窗、"确定/取消"对话框。

## 三、界面必须承载的内容板块（信息架构，硬约束）

1. **顶栏**：产品标识 BlockFace、打开图片、导出 PNG、撤销 / 重做。
2. **皮肤来源面板**——四个入口必须是**并列可见的一级入口**，不允许折叠进二级菜单：
   - a. 内置皮肤：Steve / Alex（两张**真实渲染**的头像预览卡片，可点选）
   - b. 正版账号 ID：输入框 + 查询按钮（需表达 查询中 / 找到 / 未找到 三种状态）
   - c. 上传皮肤：文件选择 / 拖放区（.png）
   - d. 皮肤 URL：输入框 + 加载按钮
   - e. 皮肤信息条：当前皮肤规格标签，需能区分 `64×64`、`64×32 旧版`、`128×128 高清`、`256×256 高清`
3. **画布**：底图 + 叠加的头像；选中态必须有可见的控制手柄（缩放 / 旋转）；要让人一眼看出"能拖、能缩放"。
4. **头像属性面板**：渲染模式（平面 / 立体）、帽子层开关、位置 X/Y、大小、旋转、不透明度、水平翻转、图层列表（支持多个头像）、删除 / 复制。
5. **状态栏**：画布尺寸、缩放比例、当前皮肤信息。

## 四、情感基调与气质关键词

**方块感（blocky）· 精确（precise）· 轻松（light）· 上手即用（instant）。**

Minecraft 的视觉基因是 16×16 像素、硬边、无渐变、有限的调色板。设计应让人一眼认出"这是给 MC 玩家做的工具"，
但**不能做成山寨的 Minecraft 官网**——它是工具，不是游戏宣传页。
气质参照区间：Teenage Engineering 的工业玩具感 × 像素艺术的克制。

## 五、输出格式（三版必须完全一致，否则无法横向对比）

- **单个 HTML 文件**，双击 `file://` 直接打开，无构建、无依赖安装。
- 视口 **1440×900**，首屏完整可见，**不出现滚动条**。
- 界面文案：**简体中文**。
- 必须呈现"**已加载一张底图 + 已放置一个 Steve 头像 + 该头像处于选中态**"的真实工作状态，不是空状态页。

## 六、硬约束（违反即返工）

1. **不得使用 Minecraft 官方 logo、商标字标或官方字体**。皮肤贴图属于玩家内容可以用；品牌标识不可以。
2. 头像必须用 `assets/headkit.js` 从**真实皮肤 PNG** 渲染。**禁止** emoji 头像、**禁止**手绘 SVG 人脸、**禁止**用 CSS 方块拼一个近似脸。
3. **正文 ≥14px，标签/注脚 ≥12px，正文对比度 ≥4.5:1。** "安静留白"风格不豁免此条。
4. **不用 emoji 当功能图标。**
5. 不引用外链图片；只允许 `assets/` 下的本地文件（Google Fonts 可选，但必须带系统字体兜底）。
6. 不编造数据：不要假统计、假用户评价、假版本号、假更新日志。

## 七、可用素材（全部就位，位于 `design-demos/assets/`）

| 文件 | 说明 |
|---|---|
| `skin-steve.png` / `skin-alex.png` | 64×64 真实默认皮肤贴图 |
| `demo-photo-a.jpg` / `-b.jpg` / `-c.jpg` | 1600×1000 真实摄影底图 |
| `headkit.js` | MC 头像渲染器（平面 / 立体 / 帽子层 / HD / legacy），已通过 15 项几何自检 |

### headkit 用法

```html
<script src="assets/headkit.js"></script>
<script>
HeadKit.loadImage('assets/skin-steve.png').then(function (skin) {
  HeadKit.renderIso(document.getElementById('c1'), skin, { size: 128, overlay: true });   // 等距立体
  HeadKit.renderFlat(document.getElementById('c2'), skin, { size: 96, overlay: true });  // 平面
});
</script>
```

`size` = 头像外接正方形边长（css px），DPR 内部已处理。等距模式下单个面边长 = `size / 2`。

## 八、视觉母题假设（供参考，不是命令）

"**方块**"是这个内容独有的、别的主题不会有的母题：整个工具可以建立在 8px / 16px 的方块网格上，
面边界、手柄、滑块、状态指示都能用同一套"像素方块"语法表达——但必须服从工具效率，不为了母题牺牲可用性。
