# BlockFace · 功能与交互规格说明

本文档定义了 BlockFace 核心功能的规格定义与交互行为边界。

---

## 1. 产品定位与信息架构

BlockFace 是一个运行于现代 Web 浏览器的纯前端 Minecraft 头像贴图与图片合成工具，核心场景为用户上传照片/截图作为底图，在上面自由贴上一个或多个 Minecraft 像素头像或通用头像图片，并导出为 PNG。

### 1.1 界面三栏架构
- **顶部操作栏 (TopBar, 60px)**：品牌 Logo、打开图片、复制到剪贴板、导出 PNG、撤销/重做、缩放适应快捷键指示。
- **左侧素材栏 (SkinPanel, 292px)**：
  - 内置经典皮肤展示（Steve / Alex，支持预加载与真实渲染）
  - 正版账号 ID 查询（支持单条或多个账号空格/换行分隔批量查询）
  - 本地皮肤文件上传（标准 64×64 / 64×32 PNG 皮肤，支持拖放/多选）
  - 外部图片 URL 导入（自动规范化 http 到 https，内置超时与三级跨域回退）
  - 本地头像图片上传（PNG / JPG / WebP 等通用图片，直接贴图，支持拖放/多选）
  - **已载入素材管理**：已注册素材列表展示、单张删除（悬浮显示垃圾桶图标）与一键清理闲置素材（带未引用与撤销历史栈引用双重保护）
- **中间画板工作区 (StageCanvas)**：
  - 无底图时提供棋盘网格与导入引导
  - 底图与头像图层实时 Canvas 合成渲染（点击任意空白处或图层自动聚焦，支持键盘操作）
  - 选框手柄（四角缩放方柄、顶部旋转旋钮）、微调指示条与浮动坐标提示
- **右侧属性栏 (InspectorPanel, 292px)**：
  - 选中头像预览（支持就地编辑图层名、实时跟随水平翻转镜像）
  - 正面第二层（帽子层）开关（通用头像图片自动禁用帽子层并标为「无」）与水平翻转开关
  - 坐标 (X, Y)、尺寸、旋转角度、不透明度精确滑杆与微调输入
  - 居中、铺满、重置快捷操作
  - 选中图层快捷操作（复制、删除，删除带二次确认超时机制）
  - 图层堆叠列表（调整层级、显隐切换、选择图层、缩略图跟随镜像翻转、支持 `Alt+↑/↓` 快捷键）
  - **画布预设管理系统**：常驻右侧面板底部，未选中或选中图层时均可随时使用：
    - 将当前画布全部头像排布一键保存为预设
    - 一键套用预设（带皮肤缺失内置兜底与大图存储优化）
    - 预设重命名与双击二次确认防误删
    - 预设文件（.json）导入与导出（自包含内嵌贴图）
- **底部状态栏 (StatusBar, 32px)**：
  - 画布物理尺寸、视口缩放比例、当前图层计数与隐私合规指示（"本地计算 · 图片不上传"）

## 2. 核心交互行为规范

### 2.1 底图与剪贴板智能识别
- **载入方式**：支持点击「打开图片」、文件选择、拖拽图片至窗口任意区域、或从系统剪贴板粘贴 (`Ctrl+V`)。
- **剪贴板意图推断**：
  - 若当前画布**无底图**：粘贴图片自动识别并设为画布底图，自动适配文档分辨率；
  - 若当前画布**已有底图**：粘贴图片自动转为贴纸图层载入素材库并贴至画布中央，不破坏现有底图。
- **分辨率与边界**：画布物理尺寸自动与底图等宽等高对齐；更换底图时不重置现有头像图层，只更新画布边界。

### 2.2 皮肤添加与图层控制
- **单选与换皮**：当选中某个已有图层时，点击新皮肤为“当前头像换肤”。
- **新增图层**：点击素材卡片添加，或通过批量输入（账号列表、多选文件）一次性生成多个图层，新头像按方阵平铺排列。
- **交互手势**：
  - 拖拽头像主体：在画布上移动位置；
  - 拖拽四角红柄：等比缩放头像尺寸；
  - 拖拽顶部引线旋钮：旋转头像角度；
  - 滚轮：光标位于头像上方时滚动缩放，按住 `Shift` 滚动旋转；
  - 键盘微调：方向键平移 1px，按住 `Shift` 平移 10px；快捷键 `[` / `]` 调整图层层级；
  - 水平翻转：支持一键翻转，属性栏预览与图层列表缩略图实时保持同步。

### 2.3 预设 (Preset) 体系
- **定义**：保存当前画布上所有头像的相对排版与贴图，不含底图本身。
- **存储优化与保护**：预设序列化时对内嵌的通用大图进行等比缩放限制（最大 512px），防止超出浏览器 LocalStorage 配额；套用预设若遇到外部网络贴图不可用，自动使用内置皮肤兜底，保持图层排版不丢失。
- **数据导出/导入**：导出为自包含 JSON 文件，皮肤贴图以内联 Base64 保存，确保脱机可用。

### 2.4 撤销与重做体系
- **历史记录栈**：图层增删、移动、缩放、旋转、属性变更、预设套用均计入撤销历史。
- **视口与文档解耦**：纯视口缩放与视口平移不污染撤销记录。
- **素材生命周期与历史栈一致性**：在清理闲置素材或单张删除素材时，若该素材在 `past` 或 `future` 撤销/重做栈中有被引用，则受保护不被清理，确保执行 `Ctrl+Z` 后图层材质完好无损。
