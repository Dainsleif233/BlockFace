# BlockFace · 功能与交互规格说明

本文档定义了 BlockFace 核心功能的规格定义与交互行为边界。

---

## 1. 产品定位与信息架构

BlockFace 是一个运行于现代 Web 浏览器的纯前端 Minecraft 头像贴图工具，核心场景为用户上传照片/截图作为底图，在上面自由贴上一个或多个 Minecraft 头像，并导出为 PNG。

### 1.1 界面三栏架构
- **顶部操作栏 (TopBar, 60px)**：品牌 Logo、打开图片、复制到剪贴板、导出 PNG、撤销/重做。
- **左侧素材栏 (SkinPanel, 292px)**：
  - 内置经典皮肤展示（Steve / Alex）
  - 正版账号 ID 查询（单条/批量）
  - 本地皮肤文件上传（标准 64×64 / 64×32 PNG 皮肤，支持拖放/多选）
  - 外部图片 URL 导入
  - 本地头像图片上传（PNG / JPG / WebP 等通用图片，直接贴图，支持拖放/多选）
  - 已载入素材与皮肤列表管理
- **中间画板工作区 (StageCanvas)**：
  - 无底图时提供棋盘网格与导入引导
  - 底图与头像图层实时 Canvas 合成渲染
  - 选框手柄、微调指示条与浮动提示
- **右侧属性栏 (InspectorPanel, 292px)**：
  - 选中头像预览与名称编辑输入框
  - 正面第二层（帽子层）与水平翻转开关（通用头像图片自动禁用帽子层）
  - 坐标 (X, Y)、尺寸、旋转角度、不透明度精确滑杆与微调输入
  - 居中、铺满、重置快捷操作
  - 选中图层快捷操作（复制、删除）
  - 图层堆叠列表（调整层级、显隐切换、选择图层）
  - 画布预设管理（保存当前头像排布为预设、一键套用、重命名、两步防误触删除、导入/导出 .json 预设文件）
- **底部状态栏 (StatusBar, 32px)**：
  - 画布尺寸、缩放比例、当前图层计数与隐私合规指示（"本地计算 · 图片不上传"）

## 2. 核心交互行为规范

### 2.1 底图管理
- **载入方式**：支持点击「打开图片」、文件选择、拖拽图片至窗口任意区域、或从系统剪贴板粘贴 (`Ctrl+V`)。
- **分辨率与边界**：画布物理尺寸自动与底图等宽等高对齐；更换底图时不重置现有头像图层，只更新画布边界。

### 2.2 皮肤添加与图层控制
- **单选与换皮**：当选中某个已有图层时，点击新皮肤为“当前头像换肤”。
- **新增图层**：点击卡片添加，或通过批量输入（账号列表、多选文件）一次性生成多个图层，新头像按方阵平铺排列。
- **交互手势**：
  - 拖拽头像主体：在画布上移动位置；
  - 拖拽四角红柄：等比缩放头像尺寸；
  - 拖拽顶部引线旋钮：旋转头像角度；
  - 滚轮：光标位于头像上方时滚动缩放，按住 `Shift` 滚动旋转；
  - 键盘微调：方向键平移 1px，按住 `Shift` 平移 10px。

### 2.3 预设 (Preset) 体系
- **定义**：保存当前画布上所有头像的相对排版与贴图，不含底图本身。
- **套用**：一键将整套头像布局应用到新底图上，自动进行边界夹取。
- **数据导出/导入**：导出为自包含 JSON 文件，皮肤贴图以内联 Base64 保存，确保脱机可用。

### 2.4 撤销与重做体系
- **历史记录栈**：图层增删、移动、缩放、旋转、属性变更、预设套用均计入撤销历史。
- **视口与文档解耦**：纯视口缩放与视口平移不污染撤销记录。
