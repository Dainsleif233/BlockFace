## 选定前的独立复核（不采信作者自述）

用自建 CDP 驱动（`tools/cdp.mjs`）重新打开三份 `file://` 稿、重新量 DOM、重新截图，并与交付的 PNG 逐像素比对：

| 指标 | A | B | C |
| --- | --- | --- | --- |
| 布局视口 | 1440×900 | 1440×900 | 1440×900 |
| scrollWidth/Height | 1440×900 | 1440×900 | 1440×900 |
| 横向/纵向溢出 | 无 / 无 | 无 / 无 | 无 / 无 |
| 最小字号 | 12.0px | 12.0px | 12.5px |
| emoji 图标数 | 0 | 0 | 0 |
| 头像 canvas 真渲染 | 8/8 | 4/4 | 7/7 |
| 与独立截图逐像素差 | 0.01% | **0%** | **0%** |

结论：三份稿均为真实渲染，A 与 B/C 在数据上等价合格；选型依据因此回到**产品形态**本身，用户选择了信息密度最高的三栏编辑器形态。

## 方向 A 的落地约束（写进 brand-spec 的部分）

- 8px 方块网格是唯一几何语法；`4px` 色条承担"分区身份"。
- 全平涂硬边：**零渐变、零 box-shadow 堆叠**，层级靠描边与色条。
- 唯一允许的"斜切"是导出按钮的切角 `clip-path`。
- 图标一律纯 CSS 方块拼装，**不得使用 emoji 或位图图标**。

## 与稿子的一处已知偏离（已向用户说明并获得实施许可）

设计稿 A/B 都把「帽子层」画成默认**关**。复核结论是：Mojang 官方 Steve 材质的帽子层本身就是不透明灰（与旧文件逐像素零差异），crafatar 独立 3D 渲染器开着帽子层的结果与我们相差 1/255 —— 即**灰帽子就是正版渲染结果，不是缺陷**。

因此实现取「**默认开 + 开关旁加一行说明**」，忠于正版渲染；用户可一键关闭。这一点与稿子不一致，已在此记录。
