# BlockFace · 设计方案决策记录 (ADR)

本文档记录 BlockFace 视觉语言与工程架构方案的决策依据。

---

## 决策背景

在产品初期设计阶段，针对 Minecraft 题材工具的界面风格与工程可行性，设计团队提出了三个独立方向：
- **方向 A (Blockgrid · 积木网格)**：严格 8px 网格，全平涂硬边，纯 CSS 像素拼装图标，高对比度设计。
- **方向 B (Vanilla Craft · 游戏原生)**：深度拟态 Minecraft 原版 GUI（石头灰质感、泥土背景、原版按钮与字体）。
- **方向 C (Neo-Pixel · 现代新像素)**：现代暗黑扁平风格，引入细微圆角与发光特效。

---

## 决策结论：采纳「方向 A · Blockgrid」

经综合评估，最终确立以 **方向 A (Blockgrid)** 作为正式设计标准，核心决策理由如下：

1. **避免法律与版权风险**：
   - 方向 B 使用了大量 Minecraft 原版素材与贴图质感，存在商标与版权边界模糊问题。
   - 方向 A 为 100% 原创几何网格与原创 CSS 拼装图标，完全杜绝版权侵权风险。

2. **专业工具感与操作效率**：
   - 扁平硬边与 8px 积木网格在信息密度、属性调节及滑块精细控制上远优于游戏原生拟物界面。
   - 界面无冗余装饰，最大程度突出画布工作区与底图内容。

3. **卓越的性能与无障碍体验**：
   - 全纯 CSS 矢量实现，零额外位图图标与网络字体请求，首屏秒开。
   - 全界面文字与关键控件均通过 WCAG AA / AAA 级别对比度审计（对比度 ≥ 4.5:1）。

---

## 关键技术规范调整记录

1. **帽子层（Overlay）默认开**：
   - 原稿标注默认关闭；实际复核确认 Mojang 官方 Steve 材质及主流 Minecraft 皮肤的帽子层均为标准正版外观，故生产版本统一设定为「默认开启」，并配备一键开关与说明提示。
2. **纯平面正脸渲染**：
   - 聚焦于贴图合成的清晰直观，移除立体等距渲染，专注保证最近邻采样下的像素精密度。
