# BlockFace · 给图片贴 MC 头像

一个**纯前端**的图片合成工具：上传一张底图，在上面贴 Minecraft 头像，随意调整大小、角度、不透明度和位置，最后导出 PNG。

没有后端、没有账号、没有上传——所有图片都只在浏览器里解码与合成。

> 独立第三方工具，与 Mojang Studios / Microsoft 无隶属关系。Minecraft 是 Mojang Studios 的商标。

## 能做什么

- **底图**：拖进窗口或点「打开图片」；不设底图也能用，导出就是透明背景。
- **头像**：皮肤正脸按整数倍最近邻放大，硬边像素不糊；可开关帽子层、水平翻转。
- **调整**：画布上直接拖动移动、拖四角方块缩放、拖顶部方块旋转；**鼠标停在头像上滚滚轮就能放大缩小，按住 Shift 再滚滚轮就转角度**；鼠标停在头像上还会浮出它的名字，图层多了也认得出谁是谁。方向键微调（Shift 加速），Delete 删除，`Ctrl+Z` / `Ctrl+Shift+Z` 撤销重做——**一整段滚轮只算一次操作，撤销一下退完**。
- **看画布**：在空白处（或底图上）按住就能把整张画布在屏幕上拖着走；滚轮缩放大小时**锚在光标上**，光标底下那块内容不会跑；工具栏的「适应窗口」一键回到居中自适应。这些只动屏幕上的位置和大小，**文档内容与撤销历史一点不受影响**。
- **多图层**：一张图上可以贴很多个头像，图层可选中、隐藏、复制、删除，**按住图层行上下拖就能调整前后遮挡顺序**（Alt + 上下方向键也行）。
- **预设 = 一张图上的全部头像**：把这张图画布上的每一个头像（位置、大小、旋转、不透明度、帽子层、翻转、显隐，以及各自的皮肤贴图）作为一个整体存成一个预设。套用会用这组头像替换画布上的头像，**底图与画布尺寸不动**，撤销一次就能退回套用前；预设保存在浏览器本地，也能导出成自包含的 JSON 文件，换台机器导入即可原样还原。
- **导出**：固定 1 倍，导出尺寸就是画布尺寸，所见即所得（头像按目标像素数渲染，边缘依旧是硬像素而不是被插值放大）。

## 皮肤从哪来

四个入口并列，随取随用：

| 入口 | 说明 |
| --- | --- |
| 内置皮肤 | 随包分发的 Steve / Alex，取自 Mojang 官方材质服务，与正版默认皮肤逐像素一致 |
| 正版账号 ID | 输入正版游戏 ID，联网取回该账号的皮肤贴图；**一次可贴多个（空格 / 逗号 / 换行隔开）** |
| 上传皮肤贴图 | 拖入或选择本地 PNG；**可一次多选，或一次拖入多张** |
| 皮肤 URL | 粘贴任意皮肤图片直链；**一次可贴多条** |

**批量添加的口径**：填一个 = 沿用原来的行为（换掉当前选中的头像，没选中就新增）；
填多个 = 每个各新增一个头像，按方阵摆开不叠在正中间，整批只占一条撤销记录。一次最多 12 个。

**皮肤格式**：64×64 现行标准、64×32 旧版、以及 128 / 256 / 512 等**高清皮肤**都支持。高清皮肤的 UV 按 `scale = 宽 / 64` 自动折算，不会出现错位的脸。

### 关于正版接口的一个事实

Mojang 官方的 `api.mojang.com` 与 `sessionserver.mojang.com` **不返回跨域响应头**，所以纯前端应用无法直接调用它们。BlockFace 因此走第三方镜像拿贴图（实测这些接口返回 `Access-Control-Allow-Origin: *`）：

1. `playerdb.co` —— 主路径，可同时拿到规范玩家名与皮肤直链
2. `mc-heads.net`、`minotar.net` —— 依次回退

同一套机制也用在图片加载上：直连 → 可选代理 → 放弃并明确告知（而不是静默产出一张坏图）。

## 快速开始

```bash
npm install
npm run dev        # 开发服务器
npm run build      # 类型检查 + 生产构建，产物在 dist/
npm run preview    # 预览构建产物
npm test           # 单元测试（核心几何与格式解析）
npm run typecheck  # 只做类型检查
```

构建产物是纯静态文件，丢到任何静态托管上即可；由于内置皮肤被内联成 data URI，不依赖任何外部请求。

## 项目结构

```

  core/                  与框架无关的纯逻辑，全部可单测
    model/               图层数据与几何：坐标变换、命中测试、缩放、旋转、边界约束
    render/              等距投影面表、头像渲染与缓存、文档合成、导出
    skin/                皮肤格式解析与 UV 区域表
    sources/             图片加载（含 CORS 三级回退）、账号与内置皮肤来源
  stores/editor.ts       唯一的状态源：文档、图层、皮肤登记表、历史记录
  components/            界面组件（顶栏 / 皮肤面板 / 画布 / 属性面板 / 状态栏）
  styles/tokens.css      设计令牌与全站组件语法
  assets/skins/          内置默认皮肤
docs/
  product-facts.md       已核实的产品事实（接口、格式、工具链）
  design-spec.md         三个设计方向的规格说明
  brand-spec.md          选定方向的品牌与界面规范
  direction-approved.md  方向决策记录
design-demos/            三个方向的 HTML 初稿与截图（已在 .gitignore 里，不入库）
tools/                   自建的验证工具链（见下）
```

## 怎么验证的

这个项目不靠"看起来对"，靠可复现的证据：

- **单元测试**（`npm test`）：缩放与旋转的数学、皮肤格式校验（含 64×32 旧版与 512 高清边界）、模板文件的解析与消毒（危险 data URI / http 链接 / 越界数值 / 超量图层）。
- **浏览器端到端**（`npm run e2e`）：脚本驱动本机 Chrome 打开真实应用，真的点卡片、真的发指针事件拖拽缩放、真的扔滚轮事件、真的走撤销重做与预设导入导出——然后读回 canvas 像素来断言，而不是看 DOM 有没有元素。其中渲染部分会把正面 8×8 共 64 个像素逐个与皮肤贴图比对，并与 crafatar 的独立实现逐像素对拍。
- **真实输入探针**（`--drag` / `--click` / `--type`）：通过 CDP Input 域发送浏览器眼里的真鼠标与真键盘，用来验证滑杆真的能拖、数字框真的能输入——合成事件测不出这类"控件在但点不到"的问题。
- **与独立实现交叉验证**：crafatar 的平面头像由另一套代码渲染，与我们的输出**逐像素完全相同**（128×128，含/不含帽子层两种，差异 0）。
  对拍只在 **64 倍整数放大**下逐格比：正脸 8 像素的几何中心正好落在两个像素的交界上，非整数倍放大时"取左还是取右"取决于尺寸奇偶，比不出真问题。
- **界面指标**：1440×900 下页面零溢出、最小字号 12px、emoji 图标数为 0。

这些工具都在 `tools/` 下，可以直接复用：

| 文件 | 作用 |
| --- | --- |
| `cdp.mjs` | 极简 Chrome DevTools Protocol 驱动：导航、求值、量 DOM、截图、下载文件，以及**真实鼠标移动 / 真实滚轮 / 真实文件选择框**（只用 Node 内置 WebSocket） |
| `e2e.js` | 在真实应用里跑的端到端断言集 |
| `probe-ui.js` | 量页面溢出、字号下限、emoji 数量、canvas 是否真的画了东西，并逐个检查交互控件有没有面积、中心点能不能点到 |
| `probe-export-pre/post.js` | 用真实鼠标点「导出 PNG」，验证 PNG 真的落盘，且尺寸就是画布尺寸（固定 1 倍） |
| `probe-gesture-pre/post.js` | 配 `--move` / `--wheel` 发浏览器眼里的真滚轮：悬停头像滚轮缩放、Shift+滚轮旋转、空白处滚轮缩放**画布视图**（锚在光标、文档不动），并验证整段手势只占一条撤销记录 |
| `probe-pan-post.js` | 配 `--drag` 用真鼠标在空白处按住拖动：验证画布整体在屏幕上平移、头像坐标与文档尺寸一动不动、这次平移不进撤销历史 |
| `probe-hover-post.js` | 配 `--move` 用真鼠标移上去，验证头像名字条浮出、贴着光标、不越界 |
| `probe-batch-pre/post.js` | 配 `--files` 走浏览器的文件选择框一次选 3 张皮肤，验证批量添加的摆位、命名与提示 |
| `probe-controls-pre/post.js` | 配 `--drag` / `--click` / `--type` 用真实鼠标与键盘验滑杆拖动、数字框输入与历史粒度 |
| `probe-contrast.js` | 逐段算出文字/图标/占位符的实际前景与合成背景，按 WCAG 公式算对比度，低于 4.5:1（大字号 3:1）就报出来 |
| `probe-hat.js` | 把官方皮肤第二层画成 ASCII，量清帽子层到底挡住哪里 |
| `probe-layerdrag-pre/post.js` | 配 `--drag` 用真实鼠标按住图层行拖动，验证排序与历史粒度 |
| `probe-preset.js` | 在底图上摆两个头像并存成预设，点导出，验证 JSON 真的落盘且只装头像 |
| `probe-preset-import.js` | 把预设序列化成文件内容 → 删掉画布上的头像 → 当成外部文件导入 → 套用，验证逐层变换与像素原样回来、底图始终没被动过 |
| `probe-rename-pre/post.js` | 配 `--click`/`--type` 用真实鼠标点铅笔、真实键盘输入，验证改名与两步删除 |
| `probe-shot.js` | 摆出一个"底图 + 两个头像 + 一个预设"的展示状态，用来出验收截图 |
| `run-e2e.mjs` | 起临时 dev server + 跑 e2e 一条龙 |
